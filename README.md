This repository is automatically replaced by the publishing workflow from the private source repository. Do not edit files here manually, because manual changes will be overwritten by the next generated release.

## Completed website

The published site includes:

- bilingual English and Arabic routes
- one shared LTR/RTL design system
- Inter and Cairo typography
- responsive layouts from narrow phones to large desktops
- an Accretion and Offset Fusion visual language
- three Hero Accretion Rings and three Accretion Nodes
- a restrained System Core heartbeat
- atmospheric section backgrounds
- an oversized AKRETUM Portfolio supergraphic
- keyboard navigation and visible focus
- `prefers-reduced-motion`
- no-JavaScript fail-open visibility
- localized SEO, canonical, `hreflang`, sitemap, favicon, and manifest
